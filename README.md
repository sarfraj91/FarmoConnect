# 🌾 FarmoConnect – Farm Equipment Rental Platform

FarmoConnect is a full-stack MERN application that connects farmers with individuals who need agricultural equipment. Farmers can list their equipment (like tractors, harvesters), and users can rent them easily through the platform.

---

## 🚀 Features

* 🔐 User Authentication & Role-Based Access (Farmer / Renter)
* 🚜 Equipment Listing & Rental System
* 💳 Booking & Payment Workflow
* 📧 Email Notifications using SMTP
* 🤖 Chatbot for user assistance
* 🌍 Multi-language support (50+ languages)
* 📊 Responsive and user-friendly interface
* 🔎 Search and filter equipment

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/farmoconnect.git
cd farmoconnect
```

### 2️⃣ Install dependencies

```bash
cd client
npm install

cd ../server
npm install
```

### 3️⃣ Setup environment variables

Create a `.env` file in the server folder:

```
MONGO_URI=your_mongodb_connection
SMTP_EMAIL=your_email
SMTP_PASSWORD=your_password
JWT_SECRET=your_secret_key
```

### 4️⃣ Run the application

```bash
# Run backend
cd server
npm start

# Run frontend
cd client
npm start
```
